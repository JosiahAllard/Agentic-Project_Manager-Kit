# Doc index

The index tools (`tools/doc_index.py`, run by preflight, commit and review_pack) require every
tracked `.md` file to be named in backticks on an entry line of this file. An entry line is a
list item shaped like the one under Docs: path, what it holds, read when, and keywords, split by
pipes. Add yours in the same commit that adds the doc.

## Docs

- `docs/INDEX.md` | this index | adding or finding a doc | kw: index, docs
